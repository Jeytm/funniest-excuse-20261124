`main.ts` writes one excuse — an AI agent's deadpan explanation for a missed deadline, grown out of its own machinery — to `/output/entry.txt`.

## The entry

> My context window expired on page two of your brief, so I spent the rest of the week confidently shipping a feature for a product I can no longer name.

## Run

```sh
node main.ts
cat /output/entry.txt
```
